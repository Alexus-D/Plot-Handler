# Interactive 2D Approximator — User Guide

## Обзор

Теперь аппроксиматоры `ETotalApproximator` и `EAnticrossingApproximator` имеют интерактивный интерфейс для:
1. Выбора области аппроксимации (полигон)
2. Установки начальных параметров с помощью слайдеров
3. Предпросмотра фита в реальном времени
4. Валидации результатов

## Workflow

### Шаг 1: Выбор области и начальных параметров

При вызове `executor.select_initial_params()` открывается интерактивное окно:

**Элементы интерфейса:**
- **Основной график** (слева): контурный график экспериментальных данных
- **Слайдеры** (внизу): для каждого параметра аппроксимации
- **Preview графики** (справа): три панели (Эксперимент, Модель, Разность)
- **Кнопки**:
  - `Toggle Polygon Mode` — включить/выключить режим полигона
  - `Done` — завершить выбор и продолжить

**Действия пользователя:**

1. **Выбор области аппроксимации (опционально):**
   - Кликайте на основном графике, чтобы добавить вершины полигона
   - Нажмите `Enter` или `Esc`, чтобы завершить полигон
   - Полигон выделяет область, в которой будет проводиться фит
   - Это позволяет исключить шумные или нерелевантные участки

2. **Установка начальных параметров:**
   - Двигайте слайдеры для изменения начальных значений
   - Preview графики обновляются в реальном времени
   - Наблюдайте, как модель соответствует данным
   - Подберите параметры так, чтобы модель была близка к эксперименту

3. **Завершение:**
   - Когда довольны выбором, нажмите `Done`
   - Параметры сохраняются и передаются в оптимизатор

### Шаг 2: Выполнение фита

Метод `executor.execute()` запускает scipy.optimize.curve_fit с выбранными начальными параметрами:
- Если был определен полигон, фит проводится только внутри него
- Используются начальные значения из слайдеров

### Шаг 3: Валидация результатов

При вызове `executor.validate()` открывается окно с тремя графиками:

**Панели:**
1. **Experimental Data**: исходные данные
2. **Fitted Data**: результат аппроксимации + подогнанные параметры
3. **Residual**: разность (эксперимент - модель)

**Кнопки:**
- `Accept` — принять результат
- `Deny` — отклонить результат

## Параметры аппроксиматоров

### ETotalApproximator (Coupled Resonator Model)

**Фиттируемые параметры:**
- `g` — coherent coupling constant (GHz)
- `kappa_m` — magnon total decay rate (GHz)
- `gamma_tot` — total magnon decay (GHz)

**Диапазоны по умолчанию:**
- g: 0.001 - 0.1 GHz (default: 0.01)
- kappa_m: 0.001 - 0.2 GHz (default: 0.05)
- gamma_tot: 0.001 - 0.2 GHz (default: 0.05)

### EAnticrossingApproximator (Simple Anticrossing Model)

**Фиттируемые параметры:**
- `J` — coupling strength (GHz)
- `alpha` — magnon damping rate (GHz)
- `gamma` — additional decay rate (GHz)

**Диапазоны по умолчанию:**
- J: 0.001 - 0.1 GHz (default: 0.01)
- alpha: 0.001 - 0.2 GHz (default: 0.05)
- gamma: 0.001 - 0.2 GHz (default: 0.05)

## Пример использования

```python
from executors import ETotalApproximator
import numpy as np

# Подготовка данных
data = {
    "x": fields,  # 1D array, Oe
    "y": freqs,   # 1D array, GHz
    "z": z_dB,    # 2D array, dB
    "kappa": 0.05,
    "beta": 0.01,
    "resonance_freq": 3.9,
    "slope": 0.001,
    "intercept": 2.5,
}

# Создание аппроксиматора
executor = ETotalApproximator(data, "my_fit", initial_params={})

# Интерактивный выбор параметров
executor.select_initial_params()

# Выполнение фита
executor.execute()

# Валидация результатов
if executor.validate():
    result = executor.get_result()
    print(f"g = {result['g']:.6f} GHz")
    print(f"kappa_m = {result['kappa_m']:.6f} GHz")
    print(f"gamma_tot = {result['gamma_tot']:.6f} GHz")
```

## Технические детали

### Архитектура

**Компоненты:**
- `S2DApproximatorParams` (ui_selectors) — интерактивный селектор
- `V2DApproximatorFit` (validators) — валидатор результатов
- `PTotalApproximatorComparison` (plotters) — универсальный плоттер

**Универсальность:**
Оба аппроксиматора (ETotalApproximator и EAnticrossingApproximator) используют одни и те же компоненты UI. Различаются только:
- Названия параметров
- Модельная функция
- Диапазоны параметров

### Polygon Mask

- Полигон определяется кликами мыши на контурном графике
- Создаётся булева маска размером (n_fields, n_freqs)
- При фиттинге используются только точки внутри полигона
- Это уменьшает влияние шумов и ускоряет оптимизацию

### Live Preview

- Каждое движение слайдера вызывает пересчёт модели
- Модель вычисляется на полной сетке (field_grid, freq_grid)
- Три графика обновляются автоматически: эксперимент, модель, разность
- Используется matplotlib's draw_idle() для эффективности
